## 原语 `/primitives`

产品

**五个原语。无限组合。**

Zintriq 不是建站工具、低代码目录、IoT 产品或 AI 生成器。那些是输出。产品是原语系统——以及你能多自由地组合它。

- **数据** — 你需要绑定的任何结构化或非结构化数据：集合、字段、关系、记录、文件、查询，以及（稍后）时序或向量。创建表、配置字段、导入并连接来源——再绑定到界面。例：构建器集合与记录；目录、联系人、预订、资产；成熟运营表的领域适配器。
- **界面** — 人看到并操作的任何表面：页面、分区、组件、表单、仪表盘、设备控件、移动外壳。可视化组合、配置属性、在各断点诚实预览。例：可视化构建器画布；顾客站点与商家仪表盘表面；二维码运行时与 PWA 外壳。
- **逻辑** — 规则、条件、触发器与流程：工作流、分支、计划、预订与签到规则，以及未来的设备或推理流水线。逻辑让界面与数据成为行为。例：工作流引擎与构建器操作；预订、签到与日历冲突规则；条件显示与表单提交路径。
- **连接** — 连接服务、人员、设备与入口：支付、SMTP/SMS、二维码、集成目录——以及规划中的 MQTT/BLE/GPIO 与 AI 端点。连接、配置凭证、映射字段。例：二维码入口与扫描体验；Stripe / Braintree 适配器（凭证另行配置）；集成目录发现。
- **发布** — 不可变发布与交付：草稿、修订、发布、回滚。站点、二维码运行时、PWA，以及未来的固件或模型 API。公开端从不读取未发布草稿。例：带稳定标识的草稿 / 已发布快照；公开路由与二维码运行时交付；回滚到先前修订。

### 组合，而非模块

没有永久的网站 / IoT / AI / 电商中心。类别由组合产生：

| 输出 | 组合 |
| --- | --- |
| 网站 | 数据 + 界面 + 发布 |
| 预订应用 | 数据 + 界面 + 逻辑 + 发布 |
| IoT 监控（规划中） | 连接 + 数据 + 逻辑 + 界面 |
| 芯片控制器（规划中） | 逻辑 + 连接 + 发布 |
| AI 预测服务（规划中） | 数据 + 逻辑 + 连接 + 发布 |

## 安全 `/security`

信任

**安全与信任**

隔离与发布语义是产品要求——不是营销事后补丁。

- 工作区隔离 — 带角色、权限与成员控制的多租户工作区。
- 草稿 / 已发布隔离 — 公开路由不得读取未发布的构建器或二维码草稿。发布是可回滚的不可变修订。
- 稳定标识 — 节点与操作保留永久 ID。外观保存绝不会重新生成标识。
- 无第三方追踪 — 设计上无广告像素。正在从技术栈移除 Google 服务。
- 数据驻留 — 从中国上海运营。应用数据存放在德国法兰克福（欧盟）。
- 密钥与包 — 社区包安装时不执行任意代码。凭证留在连接配置中——不进入已发布产物。

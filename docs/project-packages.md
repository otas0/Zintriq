# 桌面作品包（.zintriq）

桌面 Studio 可以把一个通用 Builder 作品导出成单个 `.zintriq` 文件，也可以把这样的文件导入成**新作品**。Web 模式没有这些接口，也**不提供 Studio**：未开启桌面模式时 `/studio` 为 404。

## 完整性与来源

`checksums.json` 只验证包内文件没有被改过，**不验证是谁做的包**。Community 阶段需要发布者签名后，才能把来源也纳入校验。

导入预览会提示：**包内可能含个人信息。**

## 不导出的内容

预约、客户、反馈、订单、连接凭证、数据记录、部署和密钥都不会进包。扫描到的敏感字段和字符串会记入 `content/redactions.json`，导入后标为「需要重新配置」。

工作流、动作、入口在导入后默认停用。预览会列出它们请求的外部地址，需要逐个勾选才会启用。

## 校验和

校验和证明字节一致。一个被改过的包、过高的 `schema_version`、不安全的路径，都会被拒绝，并且不会留下半个作品。
